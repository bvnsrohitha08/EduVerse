Process

How EduVerse Works

Four simple steps from classroom creation to automatic attendance recording.

1

Teacher Creates Classroom

Teacher sets up a session with subject, topic, and schedule. A unique join code is generated instantly.

2

Student Joins Session

Student logs in with their credentials and enters the virtual classroom using the join code or dashboard.

3

Interactive Teaching

Teacher broadcasts the topic. Students ask questions via live chat. The VR environment keeps everyone engaged.

4

Attendance Auto-Recorded

Login timestamps are saved to Firestore automatically. Teachers see date-wise records and percentage reports.
