# 🎓 EduVerse

EduVerse is a modern Full-Stack E-Learning Platform designed to provide an engaging online learning experience for students and instructors. The platform allows users to register, browse courses, enroll in programs, track learning progress, and manage educational content through an intuitive interface.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- 👨‍🎓 Student Dashboard
- 👩‍🏫 Instructor/Admin Dashboard
- 📚 Course Management
- 🎥 Video Learning Support
- 📝 Quizzes & Assessments
- 📊 Progress Tracking
- 📱 Responsive UI
- 🔍 Course Search
- ⚡ Fast and User-Friendly Interface

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/bvnsrohitha08/EduVerse.git
```

### Navigate to Project

```bash
cd EduVerse
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

---

## ▶️ Run Project

### Start Backend

```bash
npm start
```

or

```bash
npm run dev
```

### Start Frontend

```bash
cd client
npm start
```
